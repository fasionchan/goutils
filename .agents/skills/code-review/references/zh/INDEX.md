# 章目录与加载顺序

按下列顺序渐进打开；勿一次灌入全部章节正文。

## 加载顺序

1. `OVERVIEW.md` — 范围、非范围、严重度
2. `chapters/naming-style.md` — 命名与风格
3. `chapters/error-handling.md` — 错误处理
4. `chapters/package-api.md` — 包、API 与导出惯例
5. `chapters/concurrency-context.md` — 并发与上下文
6. `chapters/testing-maintainability.md` — 测试与可维护性
7. `chapters/security-basics.md` — 轻量安全常见坑
8. `project-specific/` — **扩展位**：有实质内容再加载；仅占位则跳过且不编造规则

## 语言门

首版只使用本目录（`references/zh/`）。`references/en/` 为后续预留，首版无实质正文。
