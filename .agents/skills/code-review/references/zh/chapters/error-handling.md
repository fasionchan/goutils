# 错误处理

通用 Go 错误处理检查项。

## 检查项

1. **检查并处理每一个 `error`**：对返回 `error` 的调用，禁止无注释地直接丢弃（`_ = f()` 或忽略返回值）；若刻意忽略，须有简短理由注释。
2. **错误要包装上下文再向上返回**：跨层返回时使用 `%w`（或项目等价包装）保留可判定性，并附带足够定位信息；避免只返回裸字符串丢失调用栈语义。
3. **不要用 panic 表达常规失败**：可预期的业务/输入/IO 失败用 `error` 返回；`panic` 仅用于真正的程序员错误或不可恢复状态，且须有明确理由。
4. **哨兵错误与类型断言要可维护**：导出的可判定错误应文档化；调用方用 `errors.Is` / `errors.As` 判定，避免脆弱的字符串相等比较。
5. **失败路径勿留下半成品副作用**：出错时注意回滚、关闭资源或使状态可观测；`defer` 中的错误若需上报，勿默默吞掉。
