# 轻量安全常见坑

轻量、常见误用清单。**本 Skill 不做完整安全审计。**

## 范围边界（必读）

以下**不在**本 Skill 首版强制范围：

- 完整安全审计 / 威胁建模 / 渗透测试
- 性能 profiling 与系统性性能证明
- 业务正确性证明

评审输出须在「未覆盖 / 超出范围」中声明上述未做。

## 检查项

1. **勿把密钥、令牌、密码硬编码进源码或提交进仓库**：凭证应来自环境变量、密钥管理或已有配置机制；审查新增常量/样例中是否含真实秘密。
2. **命令与 SQL/查询拼接要防注入**：对用户可控输入拼进 shell、SQL 或类似查询时，优先参数化/白名单；禁止未校验即拼接。
3. **路径与文件操作防目录穿越**：处理用户提供的路径时须清洗与限定根目录，避免 `../` 逃逸到敏感位置。
4. **TLS / 认证校验勿随意关闭**：生产路径禁止无必要地 `InsecureSkipVerify` 或跳过认证；若仅为测试，须隔离且不可默认开启。
5. **日志与错误信息避免泄露敏感数据**：勿把密码、完整令牌、个人敏感字段打进日志或返回给客户端。
